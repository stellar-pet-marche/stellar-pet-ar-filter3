# ペピカファミリー松戸店 10周年祭 特別ARフィルター

ペピカファミリー松戸店の10周年祭を記念した、スマートフォン向けWeb ARカメラです。記念フレームには、ステラペットマルシェ公式キャラクター「ぴーすけ」も登場します。

## ファイル

- `index.html` — ARカメラ本体。フレーム画像をHTML内に含んでいるため、追加の画像ファイルは不要です。

## GitHub Pagesで公開する

1. `index.html` と `README.md` をGitHubリポジトリの一番上の階層（ルート）にアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の **Deploy from a branch** を選択します。
4. ブランチに `main`、フォルダに `/(root)` を指定して保存します。
5. 公開が完了したら、表示されたGitHub PagesのURLをスマートフォンで開きます。

GitHubのファイル閲覧画面ではカメラは起動しません。必ずGitHub Pagesの公開URLを開いてください。公開直後は反映まで少し時間がかかる場合があります。

## 使い方

1. 公開ページで「カメラを起動する」をタップします。
2. ブラウザからカメラの使用許可を求められたら許可します。
3. 画面下の撮影ボタンで撮影します。
4. 撮影後、「写真を保存」または「共有する」を選びます。
5. 左側の切り替えボタンで前面・背面カメラを切り替えられます。

## カメラが起動しないとき

- GitHub Pagesの `https://` から始まる公開URLを開いてください。カメラの利用にはHTTPS接続が必要です。
- SafariまたはChromeで開き、ブラウザや端末の設定でカメラを許可してください。
- Instagramなどのアプリ内ブラウザで起動しない場合は、ページをSafariまたはChromeで開き直してください。
